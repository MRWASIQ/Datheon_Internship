
# Task 4 - E-Commerce Product Catalog & Shopping Cart

## Project Overview

ShopEase is a responsive e-commerce web application developed using HTML, CSS, and JavaScript.

It allows users to browse products, search products, filter categories, manage a shopping cart, and complete a demo checkout process.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- FakeStoreAPI
- Fetch API
- LocalStorage

## Features

- Display products from FakeStoreAPI.
- Product images, prices, and ratings.
- Search products by name.
- Filter products by category.
- Sort products by price and rating.
- Add products to shopping cart.
- Increase and decrease product quantities.
- Remove products from cart.
- Calculate subtotal, tax, shipping, and total.
- Save cart data using LocalStorage.
- Checkout form with customer details.
- Responsive design for different screen sizes.

## Installation and Setup

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all files are in the same folder.
4. Install the Live Server extension in VS Code.
5. Right-click index.html.
6. Select Open with Live Server.
7. The application will open in your browser.

## How to Use

1. Open the application.
2. Browse available products.
3. Search for a product by name.
4. Select a category to filter products.
5. Choose a sorting option.
6. Click Add to Cart.
7. Open the shopping cart.
8. Change product quantities or remove products.
9. Review subtotal, tax, shipping, and total.
10. Click Proceed to Checkout.
11. Enter customer details and place the demo order.

## Shopping Cart

The application uses LocalStorage to save cart items, so the cart remains available after refreshing the browser.

## Checkout Information

Checkout is for demonstration purposes only. No real payment is processed and no actual order is sent to a store.
