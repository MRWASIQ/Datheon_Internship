
# Wasiq Ali - Developer Portfolio

A responsive personal developer portfolio built using HTML5, CSS3, and JavaScript.

## Features

- Responsive design
- Dark and light theme
- Mobile navigation
- Smooth scrolling
- About section
- Technical skills section
- Academic projects showcase
- Project details modal
- Contact section
- Theme preference saved using localStorage

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Add your profile image as `profile.jpg`.
4. Open `index.html` in your browser.

## Deployment

The project can be deployed using:

- GitHub Pages
- Netlify
- Vercel
