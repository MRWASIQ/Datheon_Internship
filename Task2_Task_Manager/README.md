
# TaskFlow - Productivity Tracker

TaskFlow is a responsive task management application developed using HTML, CSS, and JavaScript.

## Features

- Create new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as active
- Task categories
- Due dates
- Search tasks
- Filter All, Active, and Completed tasks
- Dashboard statistics
- Save data using browser localStorage
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- localStorage

## How to Run

1. Download or clone this repository.
2. Open the Task2_TaskManager folder.
3. Open index.html in your browser.
4. Start adding your tasks.

No database or API key is required.

## Data Storage

Tasks are stored in browser localStorage under the key:

taskFlowTasks

Data remains available in the same browser unless its local storage is cleared.
