
# Task 3 - Real-Time Weather Forecast App

## Project Overview
WeatherNow is a responsive weather application developed using HTML, CSS, and JavaScript. It provides real-time weather information and a 5-day forecast for different cities using the OpenWeatherMap API.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Fetch API
- Local Date and Time

## Features
- Search weather by city name.
- Display current temperature in Celsius.
- Show weather conditions and icons.
- Display humidity.
- Display wind speed.
- Display atmospheric pressure.
- Show a 5-day weather forecast.
- Dynamic background based on weather conditions.
- Loading messages and error handling.
- Responsive design for mobile, tablet, and desktop.

## Project Structure

Task3_Weather_App/

## Installation and Setup

1. Download or clone this project.
2. Open the project folder.
3. Open the script.js file.
4. Add your OpenWeatherMap API key.

Example:

```javascript
var apiKey = "YOUR_API_KEY";
```

5. Save the file.
6. Open index.html in your web browser.
7. Enter a city name and click Search.

## API Used

OpenWeatherMap API

Website: https://openweathermap.org/api

The application uses:
- Current Weather API
- 5 Day / 3 Hour Forecast API

## How to Use

1. Open the application.
2. Enter a city name in the search box.
3. Click the Search button.
4. View current weather information.
5. Check the 5-day weather forecast.

## Error Handling

- Empty city name validation.
- Invalid city name message.
- API request error handling.
- Loading indicator while fetching data.
